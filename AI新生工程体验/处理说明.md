# 数据批处理与过程还原

工具读取 `原始数据/学生学号-学生姓名.tar.gz`，输出到 `已处理数据/学生学号-学生姓名/`。原始压缩包和其中的作业均不运行或修改。

先进入 `AI新生工程体验` 文件夹，再执行：

```powershell
python -X utf8 ai_experience_batch.py
```

按学号筛选：

```powershell
python -X utf8 ai_experience_batch.py --student 2506080204
```

指定输入输出目录：

```powershell
python -X utf8 ai_experience_batch.py "原始数据" --output "另一次处理"
```

默认跳过已有学生目录。`--regenerate` 仅覆盖本工具的报告，并要求压缩包哈希未改变、原始文件副本未被修改；其他人工添加文件不删除。若压缩包内容变化，请使用新输出目录。全班汇总包含本次处理及已有工具结果。

## 输出内容

- `完整性校验.md`：清单核对、异常记录、作业链接。
- `AI对话记录.md`：按会话和原始消息顺序呈现，保留角色、内容类型、工具关联和原始定位，不估算逐条时间。
- `终端时间线.md`：按实验、终端呈现录像内容，结合命令日志记录返回码；未匹配日志另列，不把日志重复等同于重复执行。
- `原始提交/`：保留包内文件原始字节和路径。
- `SHA256清单.json`：保存副本与包内数据的一致性记录。
- `处理记录.json`：工具归属、压缩包哈希及汇总元数据。
- 根目录 `批处理汇总.md`：所有学生的处理状态与报告入口。

## 边界

增量提交没有完整官方模板；manifest 没有源头内容哈希。校验通过不等于源头真实性证明、环境完整或作业完成。AI 会话时间不等于单条消息时间，终端显示时间不等于精确执行时间。本工具不拼接两类过程、不评分、不运行或修复代码。

压缩包越界路径、链接、大小超过 512 MiB、超过 100000 个成员及身份冲突会停止该学生处理。其他缺失或损坏尽量保留可读部分。批处理有失败时退出码为 1，警告或通过为 0。

工具自身验证（不运行学生作业）：

```powershell
python -X utf8 -m unittest test_ai_experience_batch test_ai_experience_ai test_ai_experience_terminal
```
