# 2026-09-17 工具修复与复跑报告

本次工作依据项目审查结果修复终端清洗与 xv6 差异报告工具，并在当前工作区的真实数据上重新生成派生产物。原始录像、原始提交和 xv6 基准均未改写。

## 已修复行为

- 终端清洗支持提示符前的 ANSI OSC/CSI 控制序列；命令提取、lab 分类和时间线不再因这些零宽控制序列落入 `other`。
- 无头录像保留首段字节并按已有解析规则重放；缺失、空、损坏或不完整的 timing 降级为无相对时间的重放，不伪造时间。
- 报告和时间线的增量命中同时要求输入指纹、处理器签名、清单结构和登记产物哈希有效。中断或部分失败不会被当作成功缓存。
- 删除全部 `term/*.out.gz` 后，报告阶段会移除同一来源清单登记的四类 Markdown，时间线阶段会移除同源时间线产物；二者均保留未登记的人工文件。损坏、异源或链接清单会拒绝清理，避免部分删除。
- 简洁时间线只读取有效时间线清单登记的 JSON，并清理源 JSON 已消失时同源登记的 Markdown，避免遗留文件被误用。
- 差异工具按清洗清单中的规范化完整原始路径匹配学生提交，避免同名目录错配。新增、删除和 Git 生成空补丁都按单文件结果准确处理。
- 默认空白符策略同时忽略空格、Tab、行尾空白和仅含空白符的空行；`--strict-whitespace` 保留这些差异供精确审阅。
- 差异报告清单只登记本工具实际写入的 `labN.md`。既有但未登记的同名人工文件不会被接管、替换或在后续缺失实验的重跑中删除。
- 仅有同源时间线清单的学生目录会继续复用；其中出现未登记的固定报告路径时，默认会分配新的学生输出目录，只有 `--overwrite` 才允许接管这些路径。可解析且指向其他来源的报告清单始终隔离；损坏的报告清单仅在同源时间线清单有效时恢复。
- 差异范围排除 xv6 Makefile 通过 `usys.pl` 生成的 `xv6-user/usys.S`；该文件不会进入个人报告、汇总统计或评分依据。Makefile、手写源码、链接脚本和 `usys.pl` 仍在比较范围内。
- 所有工具产物和清单拒绝符号链接、Windows junction 及越出学生目录的目标，并使用临时文件后原子替换。

## 回归验证

在工具目录执行了以下测试：

```powershell
python -B -m unittest -v `
  test_replay_term_qa test_timeline test_timeline_alignment `
  test_timeline_reports test_generate_readable_timeline `
  test_incremental_processing

python -B -m unittest -v test_generate_lab_diff_reports
```

结果为清洗工具 88 项通过、1 项因当前 Windows 环境不支持目录符号链接而跳过；差异工具 21 项全部通过。新增的端到端回归夹具删除一名学生的全部录像后执行 `--no-timeline`，断言四类受管报告被清理、人工 Markdown 和既有时间线保持不变；另一个夹具证明含越界路径的损坏报告清单不会造成部分删除。所有权夹具验证同源时间线不能让异源报告清单被接管。差异工具夹具还验证默认忽略仅含空白符的空行，以及人工 `labN.md` 不会被清单接管或删除。

## 当前批次复跑

实际执行：

```powershell
cd 实验过程清洗工具
python -B replay_term_qa.py "../操作系统实验数据记录" `
  --output "../操作系统实验数据记录-已清洗" --force
python -B generate_readable_timeline.py "../操作系统实验数据记录-已清洗"

cd ../代码差异报告工具
python -B generate_lab_diff_reports.py --all-labs
```

当前输入含 8 名学生、117 对录像与 timing 文件。清洗命令以退出码 `1` 结束，因为 `2306030105-何俊林-20260909-1218` 缺少 `term/`；该学生的旧同源时间线清单已标记为 `cleared`，没有生成空报告。其余 7 名学生完成处理，生成 16 份标准 JSON 时间线、16 份标准 Markdown 时间线和 16 份简洁时间线。`lab1` 至 `lab8` 的差异汇总均已生成，差异工具返回 `0`。

当前时间线共记录 288 个事件，其中 218 个 Shell 命令、35 个 Claude 用户问题和 35 个 Claude 回复；278 个事件具有绝对显示时间，10 个仅保留录像相对时间。日志时间倒退、NUL 前缀和录像头时钟差异以诊断形式保留在已清洗根 README，不被解释为成功或失败以外的推测性数据。
