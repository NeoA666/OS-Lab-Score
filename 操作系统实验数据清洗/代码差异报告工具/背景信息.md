# xv6 源码差异报告背景信息

## 目标

本工具用于操作系统实验评分时审阅学生提交的 xv6 源码变化。它以 Git unified diff 形式生成 Markdown 报告，方便教师在不运行学生代码的前提下查看每个实验的新增、删除和修改内容。

## 数据约定

- xv6 基准目录：工作区根目录的 `xv6-ai-labs-km-无答案/lab0` 至 `lab8`。
- 原始学生提交：`操作系统实验数据清洗/操作系统实验数据记录/<学号-姓名-时间>/labs/labN`。
- 已清洗学生目录：`操作系统实验数据清洗/操作系统实验数据记录-已清洗/<学生>/`。

学生目录名提供学号、姓名和采集时间。工具优先读取已清洗目录中的 `.replay_term_qa.json` 归属信息，以规范化的完整原始路径关联提交；对早期缺少归属文件的结果，仅在学生姓名唯一且目录名完全一致时回退关联，避免同名学生或同名末级目录错配。

## 比较规则

- 支持 `lab0` 至 `lab8`。学生提交中的 `labs/labN` 与基准仓库对应的 `labN` 按同一规则比较；`lab0` 同样纳入报告范围，而不是被跳过。
- 默认比较 `kernel/`、`xv6-user/`、`linker/` 下的 C、头文件、手写汇编、链接脚本、脚本以及 Makefile/`.mk` 构建配置，并比较实验根目录的 `Makefile`/`GNUmakefile`。
- 不比较文档、`TEACHER-REF/`、`target/`、`.git`/`.hg`/`.svn` 目录、系统元数据、符号链接、Windows junction 和构建产物。lab0 至 lab8 的 Makefile 都定义了 `$U/usys.S : $U/usys.pl` 并以 Perl 生成 `xv6-user/usys.S`，因此该文件不进入个人报告、汇总统计或评分依据；其生成器 `usys.pl` 仍会比较。
- 默认忽略纯空白符差异，包括仅含空格或 Tab 的空白行；使用 `--strict-whitespace` 可以进行精确比较。
- 以逐文件 `git diff --no-index` 完成比较，因此学生目录和基准目录无需是 Git 仓库。新增和删除使用 Git 可识别的 `/dev/null` 一侧；Git 返回差异状态却没有补丁时按单文件失败处理。
- 不执行学生的 Makefile、脚本或其他代码；原始提交和基准目录保持只读。

## 输出与批处理

每位学生的报告写入：

```text
操作系统实验数据记录-已清洗/<学生>/代码差异报告/labN.md
```

同目录的 `.lab_diff_reports.json` 是该工具自己的产物清单，只登记本工具写入的报告。只要清单来源仍与当前完整原始路径匹配，重新处理某个 lab 时只会删除该次选中 lab 已登记且已消失的旧报告；未登记的人工文件和未选中的 lab 报告保留。比较失败不会删除旧报告，`--all-labs` 才会按当前全部输入清理所有已登记 lab。

每个实验的跨学生汇总写入：

```text
操作系统实验数据记录-已清洗/代码差异报告汇总/labN.md
```

个人报告包含学生身份信息、实验编号、基准与提交路径、比较范围、空白符策略、文件与行数统计，以及仅包含变化文件的完整 diff。缺少学生实验目录、未匹配到已清洗目录、二进制文件或单文件比较异常都会在汇总或个人报告中明确标记，不会中断其他学生的处理。若整个原始提交目录已消失而差异报告清单仍登记旧报告，工具保留该报告、在对应汇总中标记失败并以非零状态结束。

## 工具组织

本目录仅保存源码差异报告工具、测试、使用说明和本文档。终端录像重放与时间线生成位于上级的 `实验过程清洗工具/`；原始数据、已清洗数据和历史验证记录也与本工具分离。

常用命令见 [README.md](README.md)。
