# 实验过程记录 · 学生使用说明

这个压缩包让你在自己的 Ubuntu / Debian 上完成实验并提交过程记录。
**不需要自己改配置，不需要装任何东西**——第一次运行会自动准备好。

## 两步走

### 1. 登记实验

解压后双击 **《登记实验》**（或终端里运行 `bash 登记实验.sh`）：

- 第一次运行会先准备程序（约十几秒），以后就很快；
- 填写学号、姓名，确认实验代码目录；
- 看到"登记完成，已开始记录"就开始了。

### 2. 做实验

**登记完成后新开一个终端**，在里面做实验。

> 登记之前就已经开着的终端**不会**被补录，这是故意的。请新开终端。

### 3. 提交实验

做完后双击 **《提交实验》**（或 `bash 提交实验.sh`）：

- 它会先停止记录（不会关掉你的终端，也不会打断正在跑的程序）；
- 然后打包、上传；
- **只有上传核验成功，本次登记才算结束。**

如果显示"上传未成功"：记录已经停止，但登记没结束。**再点一次《提交实验》**即可，
它会重传同一个包（内容完全一致，不会重新打包）。也可以把桌面 `实验提交包/` 里的
文件直接交给老师。

## 记录了什么

| 记录 | 不记录 |
|---|---|
| 终端里的命令、所在目录、成功与否 | 屏幕画面、摄像头 |
| 终端的显示输出（可回放） | 你的原始键盘输入 |
| 键鼠活跃时长（用于判断是否真在动手） | 密码输入（sudo 等不回显的不会落盘） |
| 实验代码目录 | 桌面其他内容 |

注意：如果你把密码写进命令行，或程序主动打印了密码，那部分会出现在记录里。

## 常见问题

- **"换台电脑还能用吗？"** 记录只在本机。换机器就重新登记、重新开始。
- **"登记后我又关掉终端重开了，之前的记录还在吗？"** 在。同一登记内新开的终端都会记录。
- **"提交后我又在旧终端敲了命令，算不算？"** 不算。提交那一刻记录就停了，请重新登记。
- **"能回看自己的录像吗？"** `labt-replay <录像名>`（录像在 `~/.labtracker/data/runs/`）。
- **"磁盘会满吗"** 一次实验通常几十 MB，程序会自动压缩旧录像。
- **"不想用了"** 运行 `bash uninstall.sh`（加 `--purge` 连数据一起删）。

## 出问题了

把界面上的提示原文发给老师。不要手动删除 `~/.labtracker`，那会让你的过程记录变少。
