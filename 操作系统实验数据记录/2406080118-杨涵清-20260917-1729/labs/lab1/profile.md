## 卡点记录
> 学生在哪个 CP 卡在哪层、给了什么提示才通
- CP①：概念题未卡（B + 27 一次答对）；卡点全在器层：①仓库根目录跑 make run 报"没有规则"→ 讲清 make 只认当前目录 Makefile，工具链其实已装好；②在 xv6 shell 敲 Linux 命令 → 讲 Linux/xv6/qemu monitor 三层世界，教"看提示符分辨"；③Ctrl+A 后误按 C 进 qemu monitor → 教 quit 与 Ctrl+A→X。
- CP①（落码阶段二次卡点，9/17）：概念答对的是 27，但动手写文件时写成了 23（与 SYS_dev 冲突），并坚持"之前完成的一部分就是改成 23"。用"23 现在有没有主"+列出全部号两步后自己发现冲突，改成 27。**信号：概念层懂，但"答案落到具体文件时要做一致性核对"这个动作没建立**——只在脑子里选题，不去核对手上的文件。
- CP②：名字来源（usys.pl 脚本生成）答对；"ecall 是内核吗"卡住 → 讲了 U 模式/S 模式 + "ecall 是唯一的门"比喻后通，随后能自己指出 `li a7, SYS_halt` 那行。usertrap 位置答对，scause==8 自己翻 trap.c 找到。器层：本次已能独立跑 `grep`、用 `nano -l` 改文件存盘，但每步仍需要给完整命令 + 预期输出。**注意：改完文件从不自查，必须每次让他跑 grep 验证。**
- CP③：概念全对（"用号当下标查 `syscalls[]`，取出格子里的函数地址跳过去"、"不加数组项会掉进 else 提示 unknown sys call 27"）。**但答对后没等指令就自己动手，把实现写到了错误文件**：在 `syscall.c` 末尾写了 `int sys_halt(void){sbi_shutdown();return 0;}`，同时撞三条错（重复定义 / 返回类型与 extern 不符 / 没 include `sbi.h`）。用"sysproc.c 186 行现在有什么→一共定义了几次"让他自己发现重复；同时讲了**声明 vs 定义 + 分文件编译/链接器模型**（这是他这次真正补上的一课）。另：自己往 `sysnames[]` 加了 `[SYS_halt] "sys_halt"`，命名与其他 26 行不同款（应为 `"halt"`），已提醒（本 lab 不要求加）。
- CP④：三问中 Q1（特权级：M vs U）、Q2（`sbi_shutdown` 不返回）均先答错后修正——Q2 用 `halt.c` 里那句 `printf("should not reach here")` 反问才转过弯，很有代表性：**他对"运行现象反推代码语义"不敏感，需要给具体锚点才能启动**。Q3 自己翻 `sbi.h` 找到了 `sbi_shutdown()`。
- 编译期插曲（9/17）：改 `sysnum.h` 时误删文件末尾的 `#endif`，报 `sysnum.h:1: error: unterminated #ifndef`。教会"报错行号是条件开始处、不是出事处" + include guard 三件套的用途。补回后 `make build` 一次通过。
- **主线验收通过（9/17）**：`make fs` → `make run` → xv6 shell 敲 `halt` → qemu 直接退出，未打印 `should not reach here`。CP①~④ 全过。

## 给下个 lab AI 的提示
> 这个学生的强弱项、该怎么教、要避免什么
- 强项（可加速的地方）：概念选择题接收快、答对率高；愿意一步步跟做，反馈及时。**抽象概念（特权级、ecall 是门、查表分发）讲一遍就能复述**。
- 弱项（要重点补的地方）：①**动手前不核对**——两次把答案落到错误的文件/错误的号上，脑子里的概念是对的，落到编辑器里就飘；②**不会读报错**，看到报错先慌，不知道行号指哪儿；③**改完不自查**，从不主动跑 grep/编译验证；④编辑器操作粗糙，`Ctrl+K` 删行会误伤相邻行。
- 教学建议：
  - 每次只给一个动作 + **明确的预期输出**；让他自己跑一遍验证再往下走（这一步绝不能省）。
  - 涉及改代码时，**先问"这个函数/这个号应该住在哪个文件"**，把它变成习惯动作——这是他最缺的一环。
  - 报错先带他读，别直接给答案：先问"报错说的是哪一行？那行本身有问题吗？"
  - 他容易跳过提问直接要代码（lab1 里出现过 2 次）。要稳住流程，但**把问题拆小、给具体锚点**（如"看 halt.c 那行 printf"）他就答得出来。
  - 编辑器可考虑教更安全的操作（undo `Alt+U`、追加行用 `echo >> `），减少误删。
  - 有答案可抄的情形（同桌提交包、原版参考）散落在桌面，**不要主动提及**，也不要用作提示来源。
