# 学生操作系统实验过程清洗工具

本目录包含三个连续阶段：终端录像与时间线清洗、xv6 源码差异报告、AI/人工贡献识别。它们读取仓库根的 `操作系统实验数据记录/`，并只向 `操作系统实验数据记录-已清洗/` 写入派生材料。

| 工具 | 用途 | 输出 |
| --- | --- | --- |
| [实验过程清洗工具](实验过程清洗工具/README.md) | 重放 `term` 录像，提取命令、终端对话与时间线 | 每名学生的过程报告与时间线 |
| [代码差异报告工具](代码差异报告工具/README.md) | 对照本地 xv6 无答案基准比较 lab1-lab8 | 每名学生和全班的差异报告 |
| [AI人工贡献识别工具](AI人工贡献识别工具/README.md) | 以过程材料和差异报告生成贡献证据 | assessment JSON 与教师报告 |

先运行实验过程清洗，再运行代码差异报告，最后按需运行贡献识别。所有入口都支持 `--help`、选择单个学生或显式传入数据根目录。原始数据和无答案基准不会被工具修改，也不会执行学生提交的代码、Makefile 或脚本。
