# OS Lab Score

面向 xv6 操作系统课程的学生提交采集、实验过程清洗、源码差异审阅、AI/人工贡献识别和诚信审核工具集。

## 工作流

1. `学生数据抓取工具/` 从课程提交服务器下载最新归档到 `操作系统实验数据记录/`。
2. `学生操作系统实验过程清洗工具/` 重放终端录像并写入 `操作系统实验数据记录-已清洗/`。
3. 同目录的代码差异与 AI/人工贡献工具继续在已清洗目录写入审阅材料。
4. `诚信判别系统/` 只读这些材料，生成教师复核报告和运行日志。

所有脚本都以自身所在位置定位仓库根目录，因而可在 Linux 服务器任意工作目录启动。输入、输出和本地依赖均可通过各工具的命令行参数覆盖。

## 目录

```text
操作系统实验数据记录/              原始提交数据（本工具写入）
操作系统实验数据记录-已清洗/       清洗与审阅产物（本工具写入）
学生数据抓取工具/                  SFTP 抓取入口
学生操作系统实验过程清洗工具/      过程清洗、差异与贡献识别工具
诚信判别系统/                      教师诚信审核工具
xv6-ai-labs-km-无答案/             本地参考基准，不纳入 Git
公共依赖/                          本地缓存依赖，不纳入 Git
```

具体安装、参数和输入约定请阅读相应工具目录的 `README.md`。

## 安全与部署

- 不要提交学生原始数据、测试数据、运行日志、`.env` 或 `*.local` 文件。
- 服务器凭据及 `NVIDIA_API_KEY` 只通过系统环境变量或密钥管理器注入。
- `公共依赖/` 与 `xv6-ai-labs-km-无答案/` 是本地目录；请按各工具 README 安装 Python 依赖并准备 xv6 基准。
- 诚信审核报告是教师复核材料，不是自动处分、评分或违规结论。
